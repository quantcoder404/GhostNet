GhostNet

GhostNet is a lightweight convolutional neural network architecture designed for mobile and edge devices. It was introduced in the paper "GhostNet: More Features from Cheap Operations" by Kai Han et al. in 2020.

GhostNet is designed to be efficient in terms of both computation and memory usage, making it suitable for real-time applications on devices with limited resources. The architecture uses a novel Ghost module that generates more feature maps from cheap operations, allowing the network to maintain high accuracy while being lightweight.

GhostNet has been shown to achieve state-of-the-art performance on various image classification benchmarks while being significantly smaller and faster than other popular architectures like MobileNet and ShuffleNet.
